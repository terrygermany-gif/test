# FinTech IRMP portfolio import

Original portfolio: https://redhatdigital.com/portfolio/innovation-refunds-erc-mobile-app-2-6/

Project: Innovation Refunds, ERC Mobile App 2.6. The source records a four-month engagement covering research, conception, visualization and testing, using Figma, FigJam, Miro and Bravo Studio. Financial figures inside screenshots are example interface content, not measured project outcomes. Revenue, acquisition-cost and lifetime-value goals are not represented as achieved results. Unrelated legacy copy (including the Audi reference) has been omitted.

The page uses the existing full-page portfolio viewer, mobile galleries, theme controls, focus handling and owner draft/preview/publish workflow. Light/dark artwork variants switch with the site theme. The hero follows the site theme; Ada’s separate black hero remains scoped to Ada.

Edit at `/edit?portfolio=fintech-irmp`. Card, hero, overview, research notes, galleries and screen order, alternate light images, prototype/design-system links, video titles/captions and uploaded video/poster replacements are editable. Media remains private until referenced by published content.

The original Figma prototype and design-system URLs are retained. Figma access has not been verified. The videos use native controls without autoplay and load on demand.
